# McDonald's UAE Win a Car: playable build (V3, flick)

- **`index.html`:** the review page you send (iion shell, CSS phone, full screen on a phone, QR on desktop).
- **`mock.html`:** the game itself, fully self-contained. Open it directly or host it anywhere.
- **Display:** fills its frame at 9:16. Any spare space takes the colour of the game's own edges.
- **Fonts:** uses Speedee automatically if it's hosted, otherwise Nunito from Google Fonts. That's the only external request.
- **`brand/`:** the supplied arches SVG, plus the smile and wordmark vector paths used in the game.
- **`MECHANIC.md`:** mechanic spec, tuning decisions and playtest results.
